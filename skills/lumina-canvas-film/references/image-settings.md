# Native image settings and exact Lumina parameter names

## Locked settings and scope

Before EVERY new character identity sheet (including family anchors, relatives and needed costume/state variants) or storyboard/composition/start/end-state image generation, read this contract and bind the actual native image controls. The following settings are mandatory for every covered job:

- Select **GPT Image 2.5 Sunburst** through the real native model selector/enum.
- Set the native **quality** control to **medium**.
- Keep native **image area** (the user's “Image Area”) **OFF**.

Apply the same locked configuration to covered generation, corrective generation and image refinement. If the operation cannot establish all three settings, hold that job and use the native recovery card. A faithful crop/reference extraction, read, attachment or existing accepted task is not a new image-generation job and must not trigger an unnecessary paid rerender. This image requirement does not change Seedance 2.5 VIDEO settings, sound rules or editor behavior, and does not impose a new model on unrelated scene/prop/research operations outside the requested character/storyboard scope.

Keep character sheets landscape 16:9 with the clear frontal face close-up plus three complete body views. Storyboards use the approved film ratio (16:9 unless explicitly overridden). Disabling image area is a separate requirement, NOT an instruction to remove aspect ratio, use a square image, zero dimensions or an empty crop. Do not guess what an unexposed area control does or treat another feature such as Panorama or Camera off as its alias.
