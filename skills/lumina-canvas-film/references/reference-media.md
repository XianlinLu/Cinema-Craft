## Character, wardrobe and emotion in motion

Read characters-voices.md for the London fashion reference and mandatory sheet checks. Keep the identity sheet neutral. In actual scenes, build emotion from the character's immediate intention and their partner's visible response. For each shared beat, specify who initiates, where they look, what their hands or body do, how the other person reacts, and how that reaction changes the next action. Use gesture, posture, shared pace, proximity, pauses, gaze and facial change to make the relationship readable. Choose interactions supported by the script and setting. An intentionally solitary scene can express emotion through the character's action and reaction to the environment.

When introducing an outfit serves the beat, start on a detail in use such as a hand closing a cuff, then hard cut to a wider view that reveals the full silhouette, the other person and the setting. The detail and reveal can be different shots or one supported continuous reveal in the same setup. Preserve the garment, contact, screen direction and emotional beat across the transition. Frame the reaction where it is legible. Specify color echoes or contrast between skin, fabrics and set under the actual scene lighting. Let the chosen action motivate the camera and costume emphasis.

## Reproduce the reference's cinematic form

For each selected moving reference, review playback and split the useful interval at observable cut or setup boundaries. Record timecodes in source time. Mark inferred lens, stabilization and speed as estimates, and describe observable screen effects when the camera mechanism cannot be verified. Record each feature present, including:

- Opening and closing frame, aspect ratio, shot size, camera height and angle, subject placement and blocking, screen direction and spatial layers.
- Camera path, direction, speed and easing, starting/ending positions, focus changes, foreground parallax, and how the movement relates to the subject.
- Hold length, action beats, speed changes, cut positions, match points, transitions and the pacing across shots.
- Light direction and quality, color and contrast, texture and depth, overlays and typography roles, framing devices and other presentation effects. Record sound or musical accents only when observed and relevant to timing.

Save a reference breakdown next to the canvas mood board. For each applicable target scene/shot, link the observed source segment and state which features to reproduce, how to stage them with the user's own subjects and setting, and any required adaptation to duration, ratio, continuity or native capabilities. Carry the mapping through the storyboard, linked technical shot details, native generation request and edit plan. Where the reference uses an unsupported or out-of-scope transition, preserve the intended pacing and match point using the approved project transition, and disclose the adaptation. Check rendered shots against the intended start/end, camera movement, framing, rhythm and presentation details. Repair observed differences within the existing budget.

Use actual media as a generation input only when use is authorized and the active native tool exposes a compatible reference input. Record the asset handle and exact segment or still used. A movement reference must stay distinct from a same-scene extension source. If direct conditioning is unavailable, use authorized supported keyframes or the timecoded description as appropriate, and record which route actually ran. Preserve the user's own script, identities and intended sound. Reproduce the observable form with original production content unless reuse of the actual media, dialogue, music, graphics or likeness is authorized for that purpose. Source ratings and visibility do not establish those permissions.
