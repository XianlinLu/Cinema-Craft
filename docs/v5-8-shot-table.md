# v5.8 镜头生产总表字段规范

总表以每个镜头一行为单位，用户可见列按以下顺序展示：

| 场景／镜头 ID | 开始时间 | 结束时间 | 画面描述 | 台词 | 景别 | 镜头焦段判断 | BGM | 音效 |
|---|---|---|---|---|---|---|---|---|

已有画面描述保留一次，原来的具体描写规范继续使用，不重复新增内容栏。原分镜板、角色／道具／音频引用、任务状态、生成模式、续写前驱与批准版本保存在同镜头关联明细中，不被删掉；旧六列紧凑展示不再代替这些独立可见列。

- **开始／结束时间**：全片累计计划时间，从 00:00:00 开始，跨场景也不归零；结束时间为下一镜开始时间，时长大于零，硬切无重叠。按实际台词时长、动作与停顿安排后累计，不分别四舍五入造成空隙。模型返回实际时长、源素材裁切时间和后期编辑时间轴分开记录。
- **台词**：保留批准剧本原文、说话人和对白／画外音／旁白归属；无台词则明确写无，不补新台词。分拆长台词保留逐字覆盖与音频对应。
- **景别**：按叙事选远景、全景、中景、近景、特写等；必要的镜内变化写起点到终点，与机位和动作匹配，不把景别当成运镜或焦段。
- **镜头焦段判断**：写全画幅等效的建议焦段或合理范围，并简述与距离、透视、空间和叙事的关系；不以景别机械推算，不宣称生成模型输出具有实测光学参数。平面／正交内容明确“不适用”并说明构图尺度。只使用实际工具支持的参数。
- **BGM**：写后期独立配乐的情绪／音色／用途、适用段落及必要进出／延续和对白下压低方案，或明确无配乐。跨镜共用音乐沿用同一音乐段 ID，未制作的资产和节拍标注计划／待测，不捏造 BPM。此列不要求分镜生成背景音乐，最终仍在原生 Video Editor 独立音乐轨中配乐并检查真实节拍。
- **音效**：列动作音、环境声、触发事件、相对镜头时间及延续关系，区分计划与实际媒体。不能因为没有台词就默认静音；应有人声与音效在分镜确认前真实可听。后期音效轨、素材和版本继续可追溯。

Agent 在现有原生“镜头生产总表确认”前自动检查列完整、时间连续、台词时长、景别／焦段／画面及声音一致性，修复遗漏，不加常规焦段／配乐问卷。通过后继续原生分镜生产。实质改变已批准内容仍用对应原生修改流程，技术补栏不重做正确图音视频。
