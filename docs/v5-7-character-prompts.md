# v5.7 人物角色提示词优化

按用户指定的角色提示词优化结论，将可执行方法整合进 `characters-voices.md`，运行时不依赖外部文档，也不增加导入文件数。原文是具体测试的经验结论，不将其推导为所有模型／题材的量化保证。

## 排版与人物设定

- 每个角色仍是一张横向 16:9 设定图；新排版替代旧的三全身等宽排版，不把两套指令混在同一提示词。
- 白色 #FFFFFF 背景，无文字和水印。左 2/5 上下放正面、严格 90 度左侧脸头肩特写，鼻尖朝画面左边，头顶至下巴完整清晰，头部约占单格七成。
- 右 3/5 左右放正／背全身服装图，仅正面全身图脸部模糊，不模糊脸部特写。两张全身图等比例、脚底与肩领线一致，手臂自然下垂，肢体完整；跨视图服装、配色、配饰、体型与身份一致。
- 提示词按“排版及一致性→已选风格与中性光影→角色设定”编译。设定包含背景身份、五官妆容、头发与服饰的版型／颜色／材质、配饰及身体比例；不空泛堆形容词。
- 可以使用简短的面部美学方向，但由剧本及用户偏好决定，不固定套用顶级神颜、古代角色或真人摄影。非人角色按物种／设计的实际解剖和材质适配。
- 光影保持可辨识、色彩稳定，使用当前风格的材质语言；不把参考用中性光影变成后续剧情灯光约束，不凭文档中的模型观察强行换图像模型。

## 自动执行与下游引用

剧本确认后自动提取角色、补全合理设计、保存提示词并调用真实原生图像工具。检查实际尺寸、视图方向、清晰／模糊范围、全身完整性及一致性；不是仅检查节点文字。全部所需角色／道具图就绪后，继续使用现有原生配图确认卡片，明确解释新设定图包含哪些视图，不新增问卷。

保存真实主图与视图引用；后续视频需要时，通过支持的原生操作从清晰脸部特写提取身份参考，从全身视图提取服装参考。不能虚构裁切文件／素材 ID，不能把模糊脸作为唯一身份源，不能把整张多视图图当成多人分镜。新排版的白底、无字与局部模糊不传播进视频画面；人物说话时脸部清晰，场景文字由已批准剧本和风格决定。政策拒绝不通过裁图、模糊或改名绕过。

已有正确批准资产继续复用，更新本身不触发重做付费素材。改动只失效真实受影响依赖；声音、原生确认、道具、镜头总表、Seedance 2.5、16:9 视频默认、保留人声音效、原生后期及最终批准后导出规则继续保留。
