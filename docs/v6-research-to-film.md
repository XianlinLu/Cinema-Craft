# v6：灵感研究到原生成片的连续流程

## 本版补齐的阶段

用户一句话 → 制作简报 → 真实灵感检索与 Mood board → 5–10 个关键词／统一视觉方向 → 原生方向选择（也可选现有风格库）→ 编剧开发与改稿 → 完整剧本确认 → 分镜脚本草案 → 角色／场景／道具实际设计与按需精修 → 合并设计确认 → 声音选择与真实试音确认 → 真实分镜图与精修、实测声音／总表 → 原生总表和分镜图共同确认 → 全部分镜视频及逐段确认 → 后期范围选择 → 原生 Video Editor 合成、配乐／字幕 → 最终预览修改闭环 → 批准后导出下载。

文字分镜草案指导配图，最终生产表根据实际资产和实测台词更新，版本分开。画面精修是真正针对缺陷调用原生图像编辑／重生，不是多写一段建议；检查通过的图片不为执行一个阶段而重复花费。场景参考独立锁定空间和状态，不能让角色设定图或孤立道具图代替完整分镜起始画面。

## 编剧方法

依据用户指定的 screenwriting-skills 影视核心与短片入口，在 story-development.md 内适配前提／主题／戏核、结构、人物与冲突、场景、对白、格式及改稿方法；类型／有机结构按题材适用。方法及许可详见 [编剧来源说明](screenwriting-notice.md)。无需在 Lumina 安装外部插件，也不依赖私人文档在线可访问。不是把上游 26 个模块全部原样打包，戏曲、剧集商业交付或长片页数不强套进短视频。

显式时长／区间优先。例如实际用户要求 30–45 秒真人片时，保持真人方向，以少量可拍事件形成完整因果，片头片尾与停顿都纳入时长。用户没指定的项目不强行沿用该时长、城市或情节。开发表在内部完成，用户看到完整剧本后用原生卡片批准，不变成多轮编剧问卷。

## 情绪版与风格库

优先实际 Pinterest 检索；电影方向用用户提供的相关名字加 film aesthetic，没有名字就用 film aesthetic，再补充具体主题／地域查询。打开实际图片并记录 pin／原始来源、观察、互动数据及可用性。只在真实可比指标存在时称为高互动候选，不能把搜索顺序等同点赞数；没有指标时标“互动数据不可见，按相关性与视觉一致性筛选”。

从已看图提炼 5–10 个不重复关键词，映射到色彩、光线、材质、构图、运动／剪辑或叙事情绪的实际制作选择。给用户展示真实板图／可访问参考及来源，原生选项提供采用研究方向、选风格库或调整。研究方向不能伪造库 slug；库方向必须读取其全部原始风格片段。搜索素材仅用于研究时不直接当已获许可的视频输入。

Pinterest 不可访问时用支持的公开图片检索或原作者来源并标注替代来源，不绕过访问限制。没有实际可看图则原生恢复或改选库，不能把生成图称为搜索成果。

## 保留的关键规则

- 画面描述保留具体主体、动作、空间互动与结果；总表独立列开始／结束、画面描述、台词、景别、焦段、BGM、音效和镜头 ID。
- 人物提示词继续采用 v5.7 优化设定图；重要特写／重复／背景物体参考继续自动生成。
- Seedance 2.5、默认 16:9、同场景连续镜头才真实续写、跨场景独立生成及硬切继续保留。
- 分镜仅去模型 BGM，确认前就必须保留正确人声、音效与环境声；最终配乐独立后期处理。
- 问答使用真实 Lumina Question，素材与编辑使用原生节点／Video Editor；确认后自动推进。旧节点／任务／正确结果复用，受理不明不重复付费，失败不冒充完成。
- 初始角色／场景／道具合并设计确认；总表与全部真实精修分镜图合并确认，不增加逐图问卷。逐段成片与最终成片批准不省略，修改在原生文本／Other 中填写。

## 发布与验证

版本 `v6.0-research-to-film`；ZIP `dist/lumina-cinema-craft-v6.zip`。两个新增运行参考，总计 40 个支持文本文件、含目录／根目录 43 项；风格规范 27 页、59 种完整正文及其内容哈希不变。打包限制维持 29,600 UTF-16 单元，低于平台 30,000 字符上限。

本次检查导入数量／字符、引用、ZIP 与当前目录一致性、风格哈希、路由与既有约束兼容，并对短时长、无角色、库风格、检索失败和恢复入口做静态流程审查。未在 Lumina 实际运行 Pinterest 搜索、付费生图精修、视频或最终导出；不能宣称这些宿主能力都已开放、没有弹窗或已完成全流程实测。
