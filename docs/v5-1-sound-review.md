# v5.1 声音修正：分镜可听、配乐后置、原生分轨

## 本次问题

用户反馈分镜视频完全无声。现有文字虽要求恢复对白，但同时允许全混轨静音和单独制作画面，容易被执行成“先交无声分镜，最后再补声音”。这次修改澄清执行顺序与验收标准；未检查用户实际 Lumina 任务的输入、音轨或混音设置，不能认定其唯一运行根因，也不宣称已经实测解决。

## 修改后的规则

1. 从批准的剧本、动作、场景推断每镜对白、画外音、旁白、音效、环境声。无可见说话人物不代表没有旁白，无对白也不代表全静音。
2. 仅移除成功输出中的模型背景配乐。无配乐时保留原声；有真实音乐分轨／原生分离时仅去音乐。全混轨静音只可作为重建中间步骤，必须恢复全部应有声音并检查口型／音效同步。
3. 每段实际可播放分镜在确认前必须有正确的应有声音；独立音频素材、字幕、波形或未来补声承诺均不能替代。无法真实处理则保留成果并说明具体原生能力阻塞。
4. 逐段确认后，在用户选定后期范围内，自动按内容、情绪、风格、节奏选择或生成原创／获许可配乐，尊重明确不配乐及用户指定音乐；不增加常规问卷。
5. 在同一 Lumina 原生 Video Editor 保留真实视频、背景音乐、所选文字字幕、音效轨，以及正确的源声或独立人声轨。不得制作假分轨、重复混入原声或提前压成一个不可编辑视频。
6. 以真实音乐节拍／乐句安排适当硬切，保留人声、音效、完整台词和关键动作；对白下压低配乐。既有续写条件、Seedance 2.5／16:9、原生卡片及错误恢复规则继续保留。
7. 播放当前真实混音预览，由原生卡片确认或修改；同一项目局部修改、重新预览。只有最终版本完全确认后才原生导出整个剪辑视频，检查音频、字幕及真实下载。
