# v5.5 镜头生产总表：具体画面与人物体验

本次参考图只用于提炼表达规范，不使用图中人物、情境、活动、陈设、灯光方案或示例句子作为项目内容。

## 写法

- 每镜在总表或可见镜头细目中保留具名“画面描述”，与机位／运镜、确切对白／旁白、声音提示分开。
- 以具体情境与体验组织：谁在何处、处于什么状态、做什么动作、如何与空间／物体互动、哪些相关感官细节支撑动作、最后有什么可见结果。只写当前镜头需要的细节，不机械凑齐所有感官。
- 通过姿态、视线、手部、接触、物体位置、通行关系及相关光声表现具体体验。情绪与功能不能仅靠抽象评价词宣称，应有批准剧本支持的行为／环境线索。
- 避免把设计方案、待办、技术术语或“提升体验／增强氛围”等口号当作画面本身。无人镜头写清具体主体与变化，不虚构人物。
- 第一人称可以帮助理解人物诉求，但不是强制文体、主观镜头指令或新增台词；不能把描述直接送去配音。实际镜头视角、台词和声音遵循原批准内容。

## 自动执行
