# v5.3 从已确认剧本自动提取角色并生成三视图

剧本确认即授权执行下一项人物图生产，不增加人物清单或外观问卷。Agent 自动通读该版完整剧本的场景、动作、出入场和对白归属，提取全部需明确身份的出镜角色，去重别名并区分同称谓的不同人物。包括无台词、短暂出场及真正具有角色身份的动物／非人角色；纯画外旁白不虚构图像，普通地点、道具和视觉特效不冒充人物。

人物外观以批准剧本、用户已有参考与选定风格为准，未指定的外观由 Agent 合理设计并在最终角色图确认中供用户调整。无需用户列人物、上传照片、手动创建节点或逐个点继续。只有真实矛盾妨碍忠实制作时才用原生卡片针对性澄清。

每个所需角色自动生成一张 16:9 横向三分区图，包含同身份、同服装／体型／发型的全身正面、侧面和背面，等比例、中性姿态、清晰分区与简洁背景。设置真实原生图像参数并检查输出尺寸；文字中写 16:9 或节点建立成功均不能替代实际图片。必要服装／状态变体关联原角色，不重复新增身份。

先完成第一张真实所需角色图只是内部提交顺序，用于发现同步／任务问题，不设置额外首张用户确认。第一张就绪后自动推进其余角色。复用匹配已有节点／图像，按既有同步恢复规则处理，不重复提交受理不明任务。

全部所需角色图真实生成并检查后展示整批图，用现有原生“角色三视图确认”卡片提供“全部通过／调整指定角色／重新查看”，通过后自动进入角色声音选择。部分图片或空节点不能完成该阶段；剧本确无出镜角色时记录原因并跳过不适用图像环节。

入口标记 `v5.3-script-cast`；导入 ZIP 为 `dist/lumina-cinema-craft-v5-3.zip`。仍为 36 个文本文件（含目录 39 项）、完整 59 种风格，其他声音、视频、原生卡片、剪辑、恢复和最终批准导出要求保留。本次是指令与包装修正，未运行 Lumina 付费角色图生成。
